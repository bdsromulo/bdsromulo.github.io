Analista de Dados com cinco anos de experiência em BI e produtos de dados, combinando análise, pipelines reprodutíveis e comunicação com áreas de negócio.

Atua com Python, SQL, Power BI e Machine Learning aplicado, priorizando análise de dados como eixo central e desenvolvimento como capacidade de construir pipelines, produtos analíticos e interfaces.

03 Projetos

Cine Brasilis

Plataforma web · Dados públicos · NLP

Plataforma de descoberta do cinema brasileiro. ~26 mil obras (ANCINE + TMDB), mapa interativo por região e recomendação por NLP (embeddings BERT multilíngue + similaridade de cosseno). Publicado em domínio próprio, com reportagem no Metrópoles.

Python JavaScript sentence-transformers BERT TMDB API

Figurona

Jogo diário bilíngue · Produto web

Jogo diário de adivinhação de figuras históricas, em português e inglês, publicado em domínio próprio. Catálogo editorial de 500 fichas com retratos, calendário de desafios anteriores, pipeline de curadoria e validação de conteúdo, testes end to end e publicação por canal de release.

TypeScript Vite Cloudflare Workers Playwright

Germany in Data

Análise econômica · Machine Learning

Investigação sobre a estagnação econômica alemã (2019–2025). Pipeline reprodutível em cinco fontes públicas, nowcasting com ElasticNetCV vs. baseline AR(1) e atribuição de fatores com XGBoost + SHAP.

Python scikit-learn XGBoost SHAP

EduData

Microdados públicos · Análise contrafactual

Impacto do ensino remoto na educação básica (2019–2024) a partir de SAEB/INEP, ENEM, Censo Escolar e INSE. Clusterização socioeconômica com KMeans e modelo contrafactual com RandomForest para medir alargamento de gaps.

Jupyter Pandas KMeans RandomForest

Oásis UTFPR

Aplicação web local-first

Aplicação web local-first e estática para acompanhamento de matriz curricular e validação de pré-requisitos em cinco cursos de engenharia. Parsing de PDFs oficiais com pdfplumber.

React TypeScript Tailwind pdfplumber

BaixaTrack

Aplicação desktop · Build automatizado

Aplicação desktop em Python para download e conversão de mídia, com build e distribuição automatizados por GitHub Actions, PyInstaller e Inno Setup.

Python GitHub Actions CustomTkinter FFmpeg
